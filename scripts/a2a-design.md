# /designer — A2A Network: UX/UI дизайн

## Контекст

Прочитай сначала:
1. `scripts/qa-reports/a2a-product-vision.md` — продуктовое видение A2A фичей
2. `scripts/qa-reports/a2a-tech-research.md` — техническое исследование и ограничения

Neva Messenger — mobile-first PWA мессенджер с AI-агентами. Стек UI: React + Tailwind + shadcn/ui, тёмная тема по умолчанию.

### Текущие экраны (прочитай файлы для контекста)
- `client/src/pages/Relationships.tsx` — экран контактов с кнопками «Кто свободен?» и «Найти человека»
- `client/src/components/network/NetworkSheet.tsx` — bottom sheet для needs/offers
- `client/src/components/agent/AgentDialogPanel.tsx` — панель A2A диалогов
- `client/src/components/agent/AgentAutonomySettings.tsx` — настройки автономии
- `client/src/components/chat/ContextPanel.tsx` — боковая панель контекста в чате

### Текущие проблемы UX
1. **«Кто свободен?»** — нет UI для результатов. Пользователь нажимает кнопку и не видит кто ответил
2. **«Найти человека»** — тяжёлая форма (категория, срочность, видимость). Высокий friction
3. **Agent Dialogs** — техническая панель, не интуитивная для обычного пользователя
4. **Autonomy Settings** — непонятно что значит каждое правило без контекста
5. **Match результаты** — нет визуализации social distance и trust

## Задачи дизайна

### 1. «Кто свободен?» — полный user flow
Спроектируй:
- **Инициация:** Как пользователь запускает запрос (текущая кнопка → куда улучшить)
- **Ожидание:** Что показывать пока ответы приходят (real-time, ответы стримятся по одному)
- **Результаты:** Как показать кто свободен, кто нет, кто не ответил. Учти:
  - Аватарки контактов
  - Статус (свободен / занят / не ответил / авто-ответ агента)
  - Контекст от агента ("Маша свободна, но у неё плохое настроение")
  - Quick actions (написать, позвонить, пригласить в группу)
- **Групповое приглашение:** Как из результатов собрать группу (чекбоксы → "Создать план")
- **Повторные запросы:** История прошлых запросов, быстрый повтор

### 2. «Найти человека» — упрощённый flow
Спроектируй:
- **Input:** Замени форму на natural language input ("Ищу дизайнера для логотипа")
- **AI parsing:** Система сама определяет категорию, срочность, видимость из текста
- **Результаты matching:** Карточки кандидатов с:
  - Аватар, имя (или "Знакомый через Колю")
  - Similarity score (визуально, не числом)
  - Trust badge
  - Social distance (прямой контакт / через 1 / через 2)
  - Кнопка "Познакомить" → запускает consent flow
- **Consent flow UI:** Как получатель видит запрос на знакомство. Не технический диалог, а human-friendly

### 3. Proactive suggestions в чатах
Спроектируй как показывать:
- В переписке с Колей: "Кстати, Маша ищет дизайнера. Коля делает дизайн — предложить познакомить?"
- Ненавязчиво, dismiss-able, в контексте разговора
- Как inline suggestion (как nudge) vs отдельная нотификация

### 4. Agent Dialog Panel redesign
Текущая панель технична. Спроектируй:
- Как показать входящие запросы human-friendly ("Иван спрашивает, свободен ли ты сегодня вечером")
- Quick response (✓ Свободен / ✗ Занят / 💬 Написать)
- Визуализация что агент сделал автоматически ("Ваш агент ответил Ивану, что вы свободны")
- Лог автономных действий (прозрачность)

### 5. Group coordination UI
Спроектируй для нового сценария:
- Пользователь хочет собрать компанию в бар
- Выбирает контакты или использует "Кто свободен?"
- Агенты координируют время/место
- Voting: "Пятница или суббота?" → каждый голосует
- Результат: "5 из 7 могут в пятницу" → создать групповой чат

### 6. Autonomy settings redesign
- Вместо таблицы "relationship × dialog type × action" → scenarios
- "Когда друг спрашивает свободен ли я — отвечать автоматически ✓"
- "Когда кто-то хочет познакомить — всегда спрашивать меня ✓"
- Toggle-based, с примерами и объяснениями

## Требования к дизайну
- **Mobile-first** (375px primary, 768px secondary)
- **Dark theme** (Tailwind dark: classes, bg-zinc-900/950 palette)
- **shadcn/ui components** (Button, Card, Sheet, Dialog, Badge, Avatar)
- **Анимации:** Framer Motion (уже в проекте)
- **Язык:** Русский
- **Accessibility:** минимум AA contrast, focus states

## Важно
- Не перегружай UI — мессенджер должен оставаться лёгким
- AI-фичи должны чувствоваться как "магия", а не как "формы"
- Consent и privacy — не мелкий шрифт, а first-class UI
- Результаты должны быть actionable (не просто список, а "что делать дальше")
